Revit-Excel Link

Export Revit schedules to Excel, edit parameter values there, and bring the changes back into the model — with a full review before anything is written.

Requirements

  • Autodesk Revit 2024, 2025, 2026 or 2027, Windows 64-bit.
  • Microsoft Excel is not required to create or read the workbooks; any .xlsx editor works.

Getting started

Open a project and click Add-Ins › Revit-Excel Link › Revit-Excel Link. The window has three areas: Export, Import and History.

Export

  1. Select schedules. Search, tick one or more schedules. Itemised schedules support editing; grouped schedules are exported as a read-only copy.
  2. Analyse. Each column is traced to its real Revit parameter and marked Editable, Editable (type), Calculated, Read-only or Related element.
  3. Export to Excel. Choose a file name. One sheet per schedule.

In the workbook:

CellMeaning
whiteEditable instance value.
blueEditable type value — one change applies to every element of that type.
greyRead-only (calculated, system or locked value). Changes are never applied.

Numbers are in the unit shown in the column heading comment. Yes/No columns offer a drop-down. Do not rename sheets, delete the hidden first column, or edit the hidden metadata sheet.

Import

  1. Save the workbook in Excel, then choose it in Import.
  2. The workbook is checked against the open project. A workbook from another project is blocked.
  3. Every value is compared three ways: the exported value, the current Revit value and the Excel value.
    StatusMeaning
    ChangeEdited in Excel only — proposed for Apply.
    Type changeType value edited — needs your approval (shows affected instances).
    Revit changedChanged in Revit since export, Excel untouched — Revit is kept.
    ConflictChanged differently in Revit and Excel, or rows disagree — you decide; nothing is overwritten silently.
    Read only / Invalid / Missing / BlockedReported, never applied.
  4. Review per schedule tab, set decisions, then click Apply and confirm.

All changes are made in one step: Undo (Ctrl+Z) in Revit reverses the whole import. A report is shown and saved to History.

Good to know

  • Formula, percentage and related-element columns (for example Room: Name) are exported blank.
  • Hidden schedule fields and rows from linked models are not exported.
  • Instance values of elements inside model groups are read-only.
  • Revit cannot clear number, Yes/No or reference values through the API; leave them filled.
  • With “Lock read-only cells” on, Excel allows filtering but not sorting. Turn it off at export to sort.
  • Reference values (Level, Phase, Material …) are matched by exact name; element ids are never accepted.

Privacy

Revit-Excel Link works entirely on your computer. Its only network request is a check of the GitHub release page for a newer version; no model, user or usage data is sent. Logs are kept in %LOCALAPPDATA%\RevitScheduleSync\Logs (30 days) and import reports in %LOCALAPPDATA%\RevitScheduleSync\Reports.

Support

For issues, contact pynxsg@gmail.com. The About button on the Revit-Excel Link tab opens a ready-made email with the version details (Email support), and Open log folder shows the log file to attach.

Updates

When a new version is published, the add-in shows a notice the next time you open Revit-Excel Link, and the About window shows a Download link. Close Revit, then run the new installer; it replaces the old version.
