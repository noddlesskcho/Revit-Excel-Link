Revit-Excel Link - installation
================================

Supports Autodesk Revit 2024, 2025, 2026 and 2027 (Windows, 64-bit).

1. Close Revit.
2. Unzip this whole folder (do not run from inside the zip).
3. Double-click Install.cmd.
4. Start Revit. The "Revit-Excel Link" panel is on the Add-Ins tab.

Installs for the current Windows user only, no administrator rights needed, to:
  %APPDATA%\Autodesk\ApplicationPlugins\RevitExcelLink.bundle

To remove: close Revit, double-click Uninstall.cmd.

Help and source: https://github.com/noddlesskcho/Revit-Excel-Link
