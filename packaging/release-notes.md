For Autodesk Revit 2024, 2025, 2026 and 2027 (Windows, 64-bit).

## Install

Close Revit first. Then use one of the two downloads below:

- **RevitExcelLink-Setup-x.y.z.exe**: run it and click through. Installs for the current Windows user,
  with no administrator rights needed. Remove it later in Windows Settings > Apps.
- **RevitExcelLink-x.y.z.zip**: unzip the whole folder, then double-click `Install.cmd`
  (`Uninstall.cmd` removes it). Use this when your computer blocks unsigned setup programs.

Then start Revit. The **Revit-Excel Link** panel is on the Add-Ins tab. The window footer and the
button tooltip show the version with its build date and time.

The setup program is not code-signed, so Windows SmartScreen may show "Windows protected your PC".
Click **More info** > **Run anyway**, or use the zip.
